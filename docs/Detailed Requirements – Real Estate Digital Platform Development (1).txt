To make our "Locked Publicly but Unlocked via WhatsApp Link" strategy work on WordPress, you do not need complex coding. You just need a specific configuration of custom fields and a user access plugin.
The WordPress Architecture You Need
To make this function automatically, you will combine three core WordPress elements:
Custom Post Types (CPT): Create a section called "Projects" instead of using standard blog posts.
Advanced Custom Fields (ACF): Create custom text boxes for project names, RERA numbers, prices, and blurred images.
A Dynamic Content Restriction Plugin: These handles showing or hiding data based on the link sent to WhatsApp.
Step-by-Step Implementation Guide
Step 1: Create the Project Pages
Use a free plugin like CPT UI (Custom Post Type UI) and ACF (Advanced Custom Fields).
Build a single template for all your real estate projects.
For each project, you will input the "Public Data" (e.g., location, configuration) and the "Gated Data" (e.g., developer name, final price sheets, floor plan PDFs).
Step 2: Set Up the URL-Based Unlock
To ensure the page unlocks only when clicked from your WhatsApp automated message, use a plugin like Dynamic Conditions (for Elementor) or Restrict Content Pro.
You will configure a rule that says: If the URL contains ?access=unlocked, show the full page. If it does not contain that parameter, show the blurred/locked version.
Example Link sent via WhatsApp: ://yourwebsite.com
Step 3: Connect WordPress to Your WhatsApp Bot
When your AI finds the top 3 matches, your automation tool (like Make.com or Zapier) will pull the matching project URLs from your WordPress database. It will automatically attach the ?access=unlocked tag to the end of the links before your bot sends them to the client's WhatsApp chat.
Recommended WordPress Tool Stack
Page Builder: Elementor Pro or Divi (Makes it incredibly easy to design the "blurred" background overlays for normal users).
Database Backend: ACF (Advanced Custom Fields) to organize all your developer details neatly.
Automation Glue: Uncanny Owl or WP Webhooks (These plugins let your WordPress site talk directly to WhatsApp tools like Wati or AiSensy without needing a middleman software like Zapier).
